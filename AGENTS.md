# AGENTS.md - Laheeb Atlas UI/UX Upgrade Instructions

## Objective
Execute a full application-wide UI/UX enhancement in one complete build.

## UI Direction
The UI must be minimal, simple, elegant, professional, clean, consistent, and suitable for a business operations system.

## UX Direction
The UX must be smooth, easy, accessible, clear, guided, and require as few clicks as possible to complete tasks.

## Scope
Apply improvements across the full app: dashboards, data management, products, orders, customers, inventory, roast batches, finance, reports, branches, system lists, tables, forms, modals, empty states, loading states, errors, and permissions.

## Product Requirement
Merge Products and Product Groups into one section called Products & Variations.

## Guidance Requirement
Every major section must include a contextual information guide explaining what the section is for, how to use it, required fields, examples, and system impact.

## Design System Requirement
Create or standardize reusable components for cards, tables, forms, filters, buttons, badges, modals, guide boxes, alerts, wizards, and detail pages.

## Accessibility
Ensure keyboard navigation, focus states, labels, contrast, clear errors, and accessible buttons.

## Testing
After implementation, run all available tests, linting, type checking, and build commands.

## Git Rule
Only commit, push, and merge to main if all checks pass successfully. Do not merge broken or partial work.
